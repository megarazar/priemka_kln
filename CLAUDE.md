# CLAUDE.md — ПринятоПро (сайт по приёмке квартир, Калининград)

## Что это за проект

Коммерческий **лид-генерационный + SEO** сайт для компании **«ПринятоПро»** — приёмка квартир/домов у застройщика и технический надзор за ремонтом в Калининграде и области. Контент на русском. Цель — заявки (форма / звонок / мессенджеры) и органический трафик по локальным запросам.

## Бренд — важно

- Компания **самостоятельная и независимая**. Рабочее название — **«ПринятоПро»**.
- Раньше план делался под франшизу **«Брик Приёмка»** — от неё **ушли**. **Не использовать брендинг «Брик»**, нет Правообладателя, нет согласований контента, нет ограничений по ценам/текстам.
- Если встретите «Брик» в старых артефактах — это легаси, меняйте на «ПринятоПро».

## Текущая стадия

**Прод-сайт уже в разработке и частично живой.** На боевом `prinyatopro.ru` (Beget) собрана **полноценная главная-лонгрид** на кастомной теме + **16 страниц-заглушек** (услуги/гео/компания — пока только H1, ждут наполнения). План ещё дорабатывается, но это уже не «только прототип».

- Цены в прототипе/документах (напр. «от 4 900 ₽») — **ориентировочные, не финал**.
- **Фактический прод-стек** (а не плановый): **WordPress + кастомная тема `prinyato`** (server-rendered PHP: `header.php`/`footer.php`/`front-page.php`, JSON-LD-схема в шаблоне; **не Bricks**) + **Yoast SEO** (Rank Math установлен, но не активен — решили не переходить) + плагин **IndexNow** (Bing/Яндекс) + **LiteSpeed Cache** (плагин есть, но **деактивирован**). Хостинг Beget. Исходники темы — в `wordpress-theme/` репозитория; деплой на сервер — по SSH.
- ⚠️ LiteSpeed деактивирован: `wp litespeed-purge all` → «not a registered command», ручной purge **не нужен**. Статика (`css/*.css`, JS) подключена с `?v=filemtime()` → кэш сбрасывается сам при деплое. Проверять страницы **только снаружи** (внутренний 127.0.0.1 на Beget = чужой Apache+PHP 5.6, даёт ложные 500).
- Боевой `prinyatopro.ru`, wp-cli по SSH. Реальные пути/нюансы/доступы — память `wp-hosting-access`.
- SEO-аудит — `seo/audit-2026-06-10/` (Health 56/100); дизайн-аудит Авроры — `design/aura-audit-2026-06-14/` (`AURADESIGN.md` + рекомендации). ⚠️ Плейсхолдеры на главной **устранены**, дизайн-P0+P1 закрыты и задеплоены (2026-06-16: реальные эксперты/фото, чистка заглушек, дисциплина красного, контраст AA, типошкала, рваные края); открыт только дизайн-**P2** (перф/CWV, мобильный above-the-fold, длина скролл-джека). Критичное из оставшегося — **наполнение 16 страниц-заглушек**.

## Сбор семантики (Wordstat / Коля)

- Семантику собирает субагент **`seo-kolya`** через MCP-сервер **`mcp-kv`** (SSE), инструмент `wordstat_get_top_requests`. Wordstat-регион: **область `10857`**, город `22`. Низкочастотка 5–25 показов/мес в регионе — уже целевой трафик, не отбрасывать.
- ⚠️ Гочча: инструменты `mcp-kv` часто **не появляются в реестре** (ToolSearch `select:wordstat_get_top_requests` пустой), хотя хост `mcp-kv.ru` живой. Решение Коли — поднять SSE-сессию MCP вручную (SSE endpoint → `initialize` → `tools/call`). Частоты не выдумывать — если API молчит, помечать `0`/`н/д`.

## Деплой

- GitHub (приватный): `https://github.com/megarazar/priemka_kln.git`, ветка `main`.
- Хостинг прототипа: **Netlify**, импорт из GitHub. `netlify.toml` задаёт `publish = "prototype"` (build command пустой — статика).
- **`git push` в `main` → автодеплой на Netlify.** Netlify публикует **только `prototype/`** — изменения в `wordpress-theme/`, `seo/`, доках на Netlify не влияют.
- Авторизация GitHub на машине — через токен в связке ключей macOS (osxkeychain). `gh` CLI и SSH-ключ для GitHub не настроены.
- **Боевой WordPress деплоится отдельно** — по SSH на Beget (не через Netlify/GitHub). Детали — память `wp-hosting-access` и `deploy-new-homepage-wordpress`.
- **Метод деплоя темы** (paramiko по SSH, доступы в `.env`): гейт «remote == ожидаемый baseline» → upload `файл.new` → `php -l` (PHP есть только на сервере, локально нет) → бэкап `файл.bak` → атомарный `posix_rename`; результат проверять снаружи (curl, при нужде Playwright). CSS локально валидировать балансом скобок + резолвом `var(--…)`.
- ⚠️ Прод-деплой (любой SSH на боевой) auto-режим **блокирует без явного «деплой»** от пользователя. Продолжение работы ≠ разрешение на выкатку — спрашивать каждый раз.
- ⚠️ css/js подключаются с `?v=filemtime` (самобастятся при деплое), **картинки — нет**: заменяя уже живое изображение, добавь `?v=<?php echo filemtime(...); ?>` к `<img src>`, иначе браузер держит старый кэш (был баг со «слетевшим» фото эксперта на ПК).
- Локальная проверка перед деплоем: PHP — только серверный `php -l` (php локально нет); **`node` тоже нет** → JS валидировать балансом делимитеров `{}()[]` (python), CSS — балансом `{}`.

## Позиционирование (точки отстройки — держать в текстах и структуре)

1. **Живые эксперты + лицо компании** (конкуренты обезличены).
2. **Официальный акт с печатью + фото с привязкой к квартире + бесплатная повторная проверка** — закрывает главную боль рынка (страх «филькиного акта»).
3. **Дистанционная приёмка «под ключ»** для иногородних (Калининград — эксклав, много инвесторов у моря).
4. **Гео-побережье**: Зеленоградск, Светлогорск, Пионерский — отдельные SEO-страницы.
5. **Контент-маркетинг** (видео реальных приёмок) — у конкурентов почти нет.

## Конвенции

- Весь контент — **на русском**, гео-фокус: Калининград + область + побережье.
- Юридические обещания (взыскание неустойки, 214-ФЗ) **сверять с актуальным законом** перед публикацией — режим неустоек с застройщиков периодически ограничивают мораториями.
- На страницах ЖК избегать «тонкого контента»: публиковать ЖК-страницу только с реально уникальной информацией (типичные дефекты, кейсы), иначе SEO-риск.
- Тема **токен-ориентированная** (`wordpress-theme/prinyato/css/tokens.css`): типошкала `--fs-*`, `--red` (действие/CTA) vs `--red-mark` (декор: eyebrow, ссылки), рваные края `--torn-clip..4`. Новые элементы — через токены, не хардкодить размеры/цвета. Закон стиля для новых страниц — `design/aura-audit-2026-06-14/AURADESIGN.md`.
- **JS темы** (`js/main.js`, IIFE-блоки): скролл-джек `[data-hscroll]` (`"desktop"`=джек на ПК / `"all"`=везде / **без значения = БЕЗ джека, лента листается пальцем** — базовый CSS `overflow-x:auto`; так листаются «оборудование» и «эксперты» на мобиле), мобильная свайп-колода услуг `.svc-deck`, count-up `[data-count]`, `.sticky-cta`, аккордеон мобильного меню. Зум-безопасность — через `window.visualViewport` (transform замораживается при `scale≠1`; `innerHeight`/`getBoundingClientRect` при зуме врут).
- **Фон/рваные края секций** заданы по ID в конце `css/styles.css`: `--sec-bg` = `paper` (`#check,#uslugi,#garant,#faq`…) / `paper-2` бежевый (`#quiz,#dop,#cta`…) / `ink` тёмный (`#trust,#distance,#granicy`). Новым страницам **переиспользуй существующие ID секций** — края заработают без правок CSS.
- **Новая страница-услуга**: WP берёт `page-{slug}.php` по слагу (без правок БД); копируй существующий хаб, переиспользуй квиз `#ppQuiz` (CF7 `id="33"`, `quiz.js`) и `.sticky-cta`.
- ⚠️ Хук безопасности блокирует `innerHTML` в JS-правках — строй DOM через `createElement`/`textContent`.
- Карта региона — **реальные тайлы** (Carto Voyager `…/rastertiles/voyager/{z}/{x}/{y}@2x.png` по curl) + пины/подписи через PIL, **не AI** (искажает географию/текст); кириллица оверлеев — `/Library/Fonts/Arial Unicode.ttf`. Фото-контент — kie.ai `gpt-image-2` (mcp-kv).
