# Приёмка КЛН — Сайт компании по приёмке квартир и технадзору

## О проекте

Коммерческий сайт для компании в Калининграде, оказывающей услуги:
- **Приёмка квартир** — проверка квартир в новостройках перед подписанием акта приёма-передачи
- **Технадзор** — строительный надзор за ходом ремонта/строительства в интересах заказчика

## Целевая аудитория

- Покупатели квартир в новостройках Калининграда и Калининградской области
- Собственники, затевающие ремонт и нуждающиеся в независимом контроле качества работ

## Задачи сайта

- Генерация заявок (лид-форма / звонок / мессенджеры)
- Объяснение ценности услуги (почему важно заказать приёмку)
- Формирование доверия (кейсы, отзывы, экспертиза команды)
- SEO-присутствие в Калининграде по целевым запросам

## Стек и инструменты

- UI-компоненты: Magic (21st.dev) через MCP
- Дизайн / прототипирование: Gamma, Miro
- Контент и SEO: Tavily, Context7
- Изображения: nanobanana-mcp (Gemini)
- База данных / бэкенд (при необходимости): Supabase

## Структура сайта (черновик)

1. **Hero** — заголовок, УТП, CTA (кнопка записи / звонок)
2. **Услуги** — приёмка квартир / технадзор / дополнительные услуги
3. **Как это работает** — пошаговый процесс
4. **Почему мы** — преимущества, цифры, гарантии
5. **Кейсы / примеры дефектов** — реальные фото, что находят специалисты
6. **Отзывы** — клиенты, Google/2ГИС
7. **Команда** — эксперты с сертификатами
8. **Цены** — тарифы на приёмку и технадзор
9. **FAQ** — частые вопросы
10. **Контакты / Форма заявки** — форма, телефон, мессенджеры, карта

## Гео-таргетинг

Калининград и Калининградская область (Балтийск, Светлогорск, Гурьевск и т.д.)
