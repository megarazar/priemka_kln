# Кластер: Гео-модификаторы (Калининград и область)

Использовать на **всех коммерческих страницах**: в Title, Description, H1 или подзаголовке, в футере, на странице контактов, в schema LocalBusiness.

## Города и посёлки области (добавить в контент / отдельные посадочные при росте)

Из README проекта + логика локального SEO. Частоты по области низкие — страницы создавать **после** основных 6 услуг.

| Город | Рекомендуемые хвосты | Показов/мес (10857) |
|-------|----------------------|--------------------:|
| **Светлогорск** | приемка квартиры светлогорск, технадзор светлогорск | 0 (оба) |
| **Зеленоградск** | приемка квартиры зеленоградск | 0 (приёмка квартиры); «приемка зеленоградск» = 5, но это **метал-приёмка** (нерелевант) |
| **Советск** | приемка квартиры советск калининградская область | 0 |
| **Балтийск** | приемка квартиры балтийск | 0–1 (на грани, н/д) |
| **Гурьевск** | приемка квартиры гурьевск | 0 |
| **Черняховск** | приемка квартиры черняховск | 0 |
| **Пионерский** | приемка квартиры пионерский | 0 |
| **Зеленоградск** | снять/купить — не наша тема; только приёмка | — |

> ⚠️ **Вывод по гео-побережью (Wordstat, июнь 2026, регион 10857):** по запросам «приёмка квартиры + город» прямого поискового спроса **нет (0)** ни в одном городе области. Это **не основание не делать страницы** — это чистый SEO/GEO-плей: спрос формируется, страница ранжируется по будущим и низкочастотным комбинациям, а основной трафик идёт от «приемка квартиры калининград» (25) + области. Гео-страницы городов держать **тонкими-но-уникальными** (типичные дефекты новостроек конкретного города, кейсы), не плодить дубли — иначе SEO-риск. Платную рекламу на города **не запускать** (спроса нет), только органика + карточки 2ГИС/Яндекс.Бизнес по зоне выезда.

## Шаблоны склейки «услуга + гео»

Подставлять к каждому кластеру:

```
приемка квартиры {гео}
приемка квартиры в новостройке {гео}
приемка квартиры от застройщика {гео}
приемка квартиры после ремонта {гео}
приемка дома {гео}
технадзор ремонта квартиры {геo}
строительный контроль ремонта {гео}
```

`{гео}` = калининград | калининградская область | светлогорск | …

## Опечатки и варианты написания

Учитывать в мета и тегах alt (не спамить):

| Вариант | Показов |
|---------|--------:|
| приемка (е) | основной |
| приёмка (ё) | в текстах для людей |
| калининиград | 9 | поймать опечатку в мелком тексте |

## Чего избегать в гео-ключах

- «купить квартиру калининград» — 1358, не наша услуга  
- «рестораны калининграда» — мусор из похожих запросов  
- «аэропорт калининград» — нерелевант
