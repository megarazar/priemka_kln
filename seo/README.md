# SEO-семантика — Приёмка КЛН (Калининград)

Семантическое ядро для сайта компании по приёмке квартир/домов и технадзору ремонтов **только в Калининграде и области**.

## Как пользоваться

1. Откройте **[00-obzor-i-struktura-sayta.md](00-obzor-i-struktura-sayta.md)** — карта кластеров → будущие страницы сайта.
2. Для каждой услуги — отдельный файл кластера с таблицами ключей, приоритетами и минус-словами.
3. При добавлении новой услуги — скопируйте шаблон из **[99-shablon-novoy-uslugi.md](99-shablon-novoy-uslugi.md)** и дополните Wordstat.

## Источник данных

- **Wordstat** через MCP KV (Yandex Cloud Search API)
- **Регион сбора:** Калининградская область (`10857`), при необходимости уточнение по городу Калининград (`22`)
- **Дата сбора:** май 2026
- **Вызовов Wordstat:** 24

> Частоты в таблицах — показы в месяц по выбранному региону. Ниша локальная, цифры небольшие — это нормально; важнее покрытие интентов и гео-хвостов.
