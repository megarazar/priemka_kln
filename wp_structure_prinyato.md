# **1\. ПОЧЕМУ WORDPRESS — АРГУМЕНТАЦИЯ ВЫБОРА**

WordPress выбран как основная CMS исходя из следующих факторов:

| Критерий | WordPress | Next.js / с нуля |
| :---- | :---- | :---- |
| Скорость запуска MVP | 5-7 дней с темой и плагинами | 10-14 дней с нуля |
| SEO из коробки | Rank Math / Yoast — полный контроль мета, Schema, sitemap | Нужна ручная настройка |
| Добавление контента | Редактор Gutenberg — без программиста | Нужен разработчик для каждой страницы |
| Страницы ЖК | Custom Post Type за 1 час, шаблон × N страниц | Отдельный файл или Dynamic Route |
| Блог | Встроен нативно | Нужна дополнительная разработка |
| Формы | WPForms / Gravity Forms — без кода | React Hook Form \+ API Route |
| Интеграции (Метрика, CRM) | Плагины за 10 минут | Через код |
| Стоимость поддержки | Низкая — контент правит SMM без программиста | Высокая — нужен разработчик |
| Гибкость дизайна | Высокая через Elementor/Bricks | Максимальная, но дольше |

*⚠ Для данного проекта WordPress является оптимальным выбором: позволяет запустить MVP за 1 неделю, даёт полный SEO-контроль через Rank Math, позволяет команде добавлять страницы ЖК и статьи блога без участия разработчика.*

| Компонент | Решение | Обоснование |

| MySQL | 8.0+ | Стандарт WP |

* Contact Form 7 — устаревший, плохая интеграция с AmoCRM

* Yoast SEO — хуже Rank Math для РФ-рынка, нет Schema сервисов бесплатно

* Elementor Free — медленный, много bloat-кода. Только Pro или Bricks

* WooCommerce — лишнее для данного сайта, замедляет

* Jetpack — монстр, устанавливает лишнее

*⚠ Принцип: чем меньше плагинов — тем быстрее сайт. Каждый плагин увеличивает время загрузки. Максимум 15 активных плагинов.*

# **5\. SEO И GEO-АРХИТЕКТУРА**

## **5.1 Настройки Rank Math (обязательно)**

| Настройка | Значение | Где настроить |
| :---- | :---- | :---- |
| Schema LocalBusiness | Тип: LocalBusiness. Адрес, телефон, координаты, часы работы Калининград. | Rank Math → Titles & Meta → Local |
| Schema Service (для CPT uslugi) | Тип: Service. serviceType из ACF. provider: LocalBusiness. | Rank Math → Custom Schema в шаблоне single-uslugi.php |

## **7.1 Обработка UTM-меток в WPForms**

**Критично для атрибуции трафика. Настройка:**

* Добавить в форму 5 скрытых полей: utm\_source, utm\_medium, utm\_campaign, utm\_content, utm\_term

* Заполнять автоматически из URL через JS-скрипт (добавить в functions.php или отдельный файл)
