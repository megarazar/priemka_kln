# План: цельный прототип главной страницы «Принято.Про»

## Контекст

Есть рабочий hero в стиле «акт приёмки / бумажное досье» (`prototype/hero.html` + `hero.css`): тёплая бумага, красные штампы, рукописная обводка (rough-notation, локально), фон-плита из GPT Image, шрифты Oswald/Caveat/PT Sans. Логотип вырезан в прозрачный PNG.

Проблемы и задачи по итогам ревью пользователя:
- **ПК-фон обрезан**, не на весь экран (сейчас плита внутри карточки `max-width:1180`).
- Тексты заточены под узкий запрос и под конкретный ЖК — нужно сделать **цельную главную про компанию в целом** (сегменты — отдельными страницами позже).
- Нужен полноценный прототип главной: смыслы, копирайтинг, SEO/GEO, UI/UX, анимации, плавный скролл, **горизонтальный скролл «лента этапов» (экраны 3–5, справа→налево, затем снова вниз)**, переделанные **хедер/футер «оторванный лист»**, **квиз** как главный инструмент захвата заявок.

Цель: премиальная, «живая» (кликабельная, SEO-индексируемая, адаптивная) главная — фоны из нейросети, весь текст/штампы/обводки/анимации — кодом. Переносимость в будущий WordPress + Bricks.

**Решения пользователя:** конкуренты = его ссылки + 4 найденных (atlantastroy.ru, priemka39.ru, profpriemka39.ru, kenigmaster.ru); интерактив = **квиз 5–7 вопросов → результат + заявка**; горизонтальный скролл = **лента этапов работы**.

⚠️ Перед стартом Фазы 1 нужны **ссылки на сайты конкурентов от пользователя** (он обещал прислать).

## Технический стек (buildless, переносимо в Bricks)

- **GSAP 3 + ScrollTrigger** — закреплённая (`pin`) горизонтальная «лента» + reveal-анимации. Стандартная лицензия бесплатна, Club-плагины не используем.
- **Lenis** (~3 КБ) — плавный скролл, синхрон с ScrollTrigger. (ScrollSmoother платный — не берём.)
- **rough-notation** (уже локально) — рукописные обводки.
- Чистый **vanilla JS**, без сборщика; всё грузится `defer` локальными файлами из `js/vendor/`. Не в критическом пути LCP (LCP = текст/фото hero, рисуется CSS).
- **Адаптив/reduced-motion обязательны:** `gsap.matchMedia` в 3 ветки — десктоп (полный пиннинг), ≤1023px (лента → вертикальный стек), `prefers-reduced-motion` (Lenis off, всё в финальном состоянии). Базовый вид корректен **без JS** (mobile-first CSS, лента = колонка по умолчанию).

## Копирайтинг / SEO-GEO (из `Карта_смыслов.md` + `seo/`)

- Тон: экспертно, без запугивания; доказательства, не обещания; «спокойная уверенность на стороне клиента». Бренд только **«Принято.Про»** (не «Брик»).
- Главная = **бренд + все услуги**, один H1 на странице; узкие ключи — на внутренние страницы (без дублей H1).
- H1/Title/Description/футер содержат **Калининград + область**; schema **LocalBusiness**. Title-ориентир: «Приёмка квартир в Калининграде — технадзор и стройконтроль».
- Цифры доверия: с 2014, 500+ квартир, 98% рекомендуют, инженеры НОПРИЗ, 90+ параметров (финал цифр — за клиентом; цены «ориентировочно»).
- Точки отстройки в текстах: живой эксперт+лицо; официальный акт с печатью + фото с привязкой + бесплатная повторная; дистанционная приёмка для иногородних; гео-побережье; контент (reels).
- ⚠️ Юробещания (неустойка, 214-ФЗ) пометить «сверить с актуальным законом».
- **Объём главной: 6000–8000 знаков чистого текста** — достаточно, чтобы закрыть SEO; достаточное число заголовков **H2/H3** (иерархия под Яндекс/Google + GEO-цитируемость).
- **Доводка текстов (обязательный шаг после копирайтинга Жени, до вёрстки):** прогнать тексты через **`/humanizer`** (убрать признаки AI, сделать живым/интересным) → **`/copywriting`** (усилить продающую/вовлекающую часть). Итог — SEO-оптимизированный И человечный текст, не «роботный».

## Хедер/футер «оторванный лист»

`mask-image` со SVG-краем (feTurbulence/displacement) — органичный рваный край, векторный, реколорится, сохраняет текстуру бумаги; `filter:drop-shadow` для глубины. Два SVG-маска (`torn-bottom`, `torn-top`) в `assets/img/`. Фолбэк `@supports not (mask-image)`. Стики-обёртка не клипается (маска на внутреннем слое). Мобильное меню — бургер (`header.js`).

## Квиз (vanilla JS, `quiz.js`)

6 шагов → сегмент: тип объекта → отделка → площадь → город → что беспокоит → когда приёмка. Рендер-из-состояния (`STEPS` — конфиг-массив, легко править/портировать в ACF). Опции — крупные «штамп-карточки» (настоящие `<input radio>`, доступны с клавиатуры). Прогресс «X из 6».
Результат (`computeResult`) → один из 4 сегментов (А локальная приёмка / Б дистанционная / В дом / Г конфликт-неустойка) + модификаторы (тепловизор при отделке) + ориентировочная цена (конфиг `PRICES`, «ориентировочно»). Результат = стилизованная карточка «предварительное заключение» со штампом → форма имя+телефон (маска `+7`, валидация, `aria-live`, успех-штамп «Заявка принята»).
Backend-ready: единый `payload` + `submitLead()` стаб (localStorage/console) + `data-endpoint` — позже заменить на `fetch` в CRM/WPForms.

## Новые ассеты через GPT Image 2 (warm-paper/red-stamp)

1) 5 «карточек-этапов» (4:5, штамп №01–05). 2) 3–4 фото-услуги «как приклеенный документ» (3:2). 3) Оборудование крупно: тепловизор/нивелир/пирометр/эндоскоп (4:3). 4) 2–3 портрета экспертов (4:5, со скрепкой). 5) Образец акта с печатью (3:4, блюр/ватермарк). 6) Гео-карта побережья (16:9, штамп-пины). 7) Постеры видео (16:9, чтобы не автоэмбедить). Для ключевых — desktop+mobile кропы, WebP+фолбэк, ≤150 КБ. Оптимизировать `logo.png` (440 КБ → 30–60 КБ/SVG).

## Последовательность работ (этапы)

- **Этап 0.** Каркас `css/`+`js/vendor/`, вынести токены из `hero.css` в `tokens.css`, подключить GSAP/ScrollTrigger/Lenis, перенести rough-notation. Hero не сломан.
- **Этап 1.** `index.html`: все 14 секций как заглушки в нужном порядке; mobile-first вертикальный стек, читаемо без JS. Перенести ч/б-вайрфрейм в `legacy/`.
- **Этап 2.** Хедер/футер «оторванный лист» + бургер + оптимизированный логотип.
- **Этап 3.** Интеграция hero как секция 1 (+ фикс ПК-фона: **плита full-bleed на весь экран 16:9**, контент в `max-width`-контейнере; при необходимости сгенерить более «чистый» широкий фон). Убрать упоминание конкретного ЖК сверху; переписать копию под компанию в целом.
- **Этап 4.** Статичные секции 2,4,5,6,7,8,9,10,11,13 — реальная копия, фото, lazy-load, FAQ на `<details>`.
- **Этап 5.** Плавный скролл + reveals (Lenis+ScrollTrigger, гейтинг `html.js-anim`, reduced-motion).
- **Этап 6.** Закреплённая горизонтальная «лента этапов» (`process.js`, 3-веточный matchMedia, мобильный вертикальный фолбэк).
- **Этап 7.** Квиз (`quiz.js`) — главный конвертер, со штампом-результатом.
- **Этап 8.** Перф-проход: WebP+`width/height` (CLS), preload hero+шрифты, self-host шрифтов, `defer` JS; цель LCP <2.5с / mobile >70.
- **Этап 9.** QA (Фаза проверки ниже) + заметки для переноса в Bricks.

(Перед Этапом 3 — отдельная под-задача: **разбор структуры конкурентов** (ссылки пользователя + 4 известных) через web, чтобы дёрнуть удачные блоки/паттерны и заложить в копию и порядок.)

## Проверка (verification)

- Локально: `cd prototype && python3 -m http.server 8777` → `http://localhost:8777/`.
- Скриншоты Playwright MCP: десктоп 1440×900 и мобайл 390×844 по каждой секции; прокрутка «ленты» (pin → горизонт. → unpin → resume); квиз по шагам + результат/успех.
- `prefers-reduced-motion: reduce`: Lenis off, нет пиннинга, лента = вертикальный стек, reveals мгновенно.
- Без JS: полная читаемость, FAQ работает, телефон/ссылки кликабельны.
- Клавиатура/a11y: таб по хедеру и всему квизу; фокус на новый шаг; контраст ≥4.5:1.
- Lighthouse (mobile): LCP-элемент = hero, LCP <2.5с, без CLS; GSAP/Lenis `defer`, не блокируют рендер.
- Резайз через границу 1023↔1024: чистое переключение горизонт↔вертикаль.

## Риски

- **Горизонтальный pinned-скролл — самое рискованное** (выравнивание, резайз, ощущение «scroll-jacking»): `scrub`, `invalidateOnRefresh`, travel == overflow (1:1), всегда вертикальный фолбэк.
- Перф vs +~70 КБ GSAP: `defer`, вне LCP, WebP, lazy, self-host шрифтов; видео — постеры, не автоэмбед (YouTube в РФ не грузится).
- В Bricks: код ScrollTrigger в Code-элементе секции; WP Rocket «delay JS» не должен откладывать GSAP/Lenis; не включать второй плагин плавного скролла.
- Перенос `index.html`: новая главная становится `index.html` (автодеплой на Netlify); старый ч/б — в `legacy/` (подтвердить перенос).
- Квиз→CRM: реальный `<form>` + `payload` + `data-endpoint`; позже заменить стаб на `fetch`.

## Исполнение через многоагентный «офис» Nero (гибрид)

Главную делаем **многоагентно**, но честно распределяя по сильным сторонам ролей — потому что офис заточен под SEO-лонгриды (canvas-hero, PHP-шаблон), а у нас премиальный многосекционный дизайн «акт/досье» под Bricks. Поэтому:

**Роли офиса берут на себя (их сила):**
- **Артём (artyom)** — разбор структуры конкурентов (4 известных + ссылки пользователя) → удачные блоки/паттерны. Закрывает под-задачу «анализ конкурентов».
- **Коля (seo-kolya)** — SEO-ядро/мета для главной (на базе `seo/`), один H1, гео.
- **Женя (zhenya)** — копирайтинг всех 14 секций (про компанию в целом, по `Карта_смыслов.md`, тон «доказательства, не обещания»).
- **Лёня (lenya)** — финальный SEO/GEO-аудит. **Макс (qa)** — браузерный QA (рендер, консоль, адаптив, ссылки).

**Кастомный дизайн-трек (Директор=я, не дефолт офиса):** hero-досье, **GSAP лента этапов**, **квиз**, хедер/футер «оторванный лист», плавный скролл. Алину/Бориса/Наташу подключаем только с **жёстким брифом нашего стиля** (тёплая бумага, #cc2018, штампы, rough-notation, GSAP), иначе они уйдут в свой canvas-longread. Картинки — через GPT Image 2.

**Важно про правила офиса:** `plugin/rules/*.mdc` — это Cursor-правила, в Claude Code **не загружаются автоматически**. Поэтому Директор в начале запуска обязан прочитать `plugin/agents/director.md` и `plugin/rules/*.mdc` (russian-only, site-context, nero-network-office, shared-bank) и применять их вручную/передавать ролям.

**Зависимость:** перед разбором конкурентов нужны **ссылки от пользователя** + 4 известных (atlantastroy.ru, priemka39.ru, profpriemka39.ru, kenigmaster.ru).

**Старт в новом чате:** (1) сессия перезапущена → 11 субагентов доступны; (2) прочитать `ПЛАН_главной_страницы.md` + `plugin/agents/director.md` + `plugin/rules/*.mdc`; (3) запустить Артёма (конкуренты) и Колю (SEO) параллельно → Женя (копия) → дизайн-трек (hero/лента/квиз) → Наташа-сборка с брифом → Юра-публикация на prinyatopro.ru по SSH → Макс+Лёня.
