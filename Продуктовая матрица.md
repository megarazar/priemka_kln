## 5. Продукт №2. Технический надзор ремонта

| Параметр | Описание |
| --- | --- |
| Суть продукта | Регулярный независимый контроль качества ремонтных работ на объекте клиента. |
| Для кого | Собственники квартир и домов, которые делают ремонт со строительной компанией, частной бригадой, дизайнером, прорабом или удалённо. |
| Ключевая боль | Клиент боится плохого качества, необоснованных доплат, затягивания сроков, скрытых нарушений и будущих проблем после ремонта. |
| Что входит | Выезд инженера, осмотр выполненных работ, контроль качества, технологии, скрытых работ и этапов, соответствия строительным нормам, проекту, дизайн-проекту и визуально проверяемому качеству выполнения работ. |
| Что не входит | Спор со строителями, юридическое сопровождение, управление ремонтом, ежедневный контроль бригады, ответственность за действия подрядчиков, решение за клиента — платить или не платить. |
| Формат | Месячное сопровождение ремонта. Доступны два формата: «Технадзор мини» — 2 плановых выезда в месяц для объектов до 80 м²; «Технадзор стандарт» — 4 плановых выезда в месяц, ориентир один выезд в неделю. Оплата вперёд. |
| Критические этапы | Инженерные сети, сантехника, электрика, гидроизоляция, штукатурка, шпаклёвка, плиточные и малярные работы, финальная сдача. |
| Принцип проверки | Проверка только личным выездом инженера. Фото и видео от клиента не заменяют технический осмотр. |
| Документ | Акт технического надзора ремонта после каждого выезда: что проверено, что выполнено, какие есть замечания, фото, рекомендации и статус по этапу. |
| Сроки | Предварительное резюме — в течение 2–3 часов. Полный акт — не позднее 24 часов после выезда. |
| Цена / ориентир | «Технадзор мини» для объектов до 80 м² — 16 000 ₽/мес за 2 плановых выезда. «Технадзор стандарт» — от 30 000 ₽/мес за 4 плановых выезда; стоимость для объектов свыше 80 м² определяется тарифной сеткой. |
| Маркетинговая формула | Технический контроль ремонта, чтобы клиент понимал, за что платит строителям. |

> **Важная формулировка для инженеров:** Инженер не рекомендует клиенту платить или не платить подрядчику. Инженер фиксирует техническое состояние работ и даёт заключение по качеству. Решение об оплате клиент принимает самостоятельно в рамках своих договорённостей с подрядчиком.

| Для кого | Клиенты, у которых ремонт уже идёт, появились сомнения, возник конфликт, нужно проверить этап или понять реальное состояние объекта. |
| Ключевая боль | Клиент не понимает, нормально ли выполняются работы, есть ли нарушения, критична ли ситуация и что требовать от строителей. |
| Что входит | Выезд инженера, осмотр текущего состояния ремонта либо выбранного этапа работ, проверка доступных объёмов проверяемого этапа, фотофиксация, выявление замечаний, рекомендации и акт. Этапом могут быть: электрика, сантехника, инженерные сети, штукатурные, малярные, плиточные и иные строительные работы. |

| Повторное приглашение | Клиент может повторно пригласить инженера на этот же объект. Это оформляется как новый разовый выезд либо как переход в месячный технический надзор. |

| Роль в продажах | Вход в воронку: после аудита или приёмки отдельного этапа можно предложить месячный технадзор, повторный выезд, финальную приёмку или консультацию инженера. |

| Что не входит | Юридическое сопровождение, спор с подрядчиком, управление устранением дефектов, гарантия исправления замечаний, бесплатные повторные выезды, проверка скрытых этапов без возможности доступа. |

| Повторные выезды | Оплачиваются отдельно. Рабочая логика: до 2 повторных проверок, каждая со скидкой 50% от действующего тарифа проверки. |
| Сроки | Осмотр 1–2 часа. Предварительное резюме — 2–3 часа. Полный акт — до 24 часов. |
| Особый случай | Если клиент находится на месячном техническом надзоре, финальная проверка может быть проведена как один из плановых выездов оплаченного месяца. Если плановые выезды исчерпаны либо проверка требуется вне оплаченного периода, услуга оплачивается отдельно. |
| Маркетинговая формула | Проверьте ремонт перед финальным расчётом со строителями. |

## 11. Продуктовая лестница

### Сценарий 1. Клиент купил квартиру
1. Приёмка квартиры от застройщика.
2. Повторный выезд после устранения замечаний, если нужен.
3. Если клиент планирует ремонт — предложение технического надзора ремонта.
4. При запросе клиента — передача менеджеру по пулу проверенных подрядчиков.
5. Технический надзор ремонта на ключевых этапах.
6. Финальная проверка может быть проведена как один из плановых выездов оплаченного месяца технического надзора. Если плановые выезды исчерпаны либо сопровождения не было, финальная приёмка оплачивается отдельно.

### Сценарий 2. Клиент уже делает ремонт
1. Разовый технический аудит ремонта.
2. Если выявлены риски — предложение месячного технического надзора.
3. Регулярные выезды и акты после каждого выезда.
4. Финальная проверка может быть проведена как один из плановых выездов оплаченного месяца сопровождения. Если плановые выезды исчерпаны либо клиент не был на надзоре, финальная приёмка оплачивается отдельно.
5. При необходимости — повторные проверки после устранения замечаний.

### Сценарий 3. Клиент почти закончил ремонт
1. Финальная приёмка ремонта.
2. Акт замечаний.
3. Повторная проверка после устранения замечаний.
4. Если замечания не устранены после повторных проверок — клиенту передаются документы, дальше возможна работа с юристом по отдельному запросу.

### Сценарий 4. Клиент строит дом
1. Пилотный технический контроль строительства дома.
2. Только при наличии профильного эксперта.
3. Не смешивать с основной продуктовой линейкой до подтверждения модели.
