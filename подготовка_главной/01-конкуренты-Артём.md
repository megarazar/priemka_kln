## ЧАСТЬ 2. СИНТЕЗ ДЛЯ ГЛАВНОЙ «ПРИНЯТО.ПРО»

### ТОП-10 рабочих блоков/паттернов (откуда подсмотрено)
1. **Цифры доверия лентой сразу под hero** (4 метрики) — Догма, приемка.москва, profpriemka. Например: дефектов на квартиру, принято объектов, % устранённых застройщиком, лет на рынке.
2. **«Что мы проверяем» иконками высоко на странице** — profpriemka, Догма (70+ параметров). Снимает вопрос «а что вообще смотрят».
3. **Интерактивный калькулятор стоимости** (площадь+комнаты+ЖК+допы+скидки за несколько квартир) — profpriemka, приемка.москва. Сильный CTA + квалификация лида.
4. **Таблица сравнения «БЕЗ нас / С нами»** — приемка.москва. Наглядно продаёт ценность.
5. **Оборудование с пояснением «зачем»** (фото прибора + что выявляет) — profpriemka, Догма, Ситипроф. Образовательно, повышает доверие. Интерактив «включить тепловизор» — Ситипроф.
6. **Процесс из 4–5 этапов** (заявка → выезд → акт+ведомость → претензия → бесплатная повторная) — Догма. У нас это ляжет на GSAP-ленту этапов.
7. **Команда с лицами и опытом** (карточки инженеров) — приемка.москва, Ситипроф. Наша ключевая отстройка — «живые эксперты».
8. **Видео-отчёты реальных приёмок на главной** — Ситипроф, priemka39 (видеообзор). Почти ни у кого в КЛН нет качественного видео-контента → наша зона роста.
9. **Контент-блоки, закрывающие возражения**: «3 ошибки новосёла», «5 признаков хорошего спеца», FAQ с гарантиями — Догма. Ловят инфо-трафик + снимают страхи.
10. **Многошаговый квиз с сегментацией** (тип объекта / с отделкой или без / иногородний ли) — atlantastroy (инвест-квиз), priemka39 (тест «готовы сами?»). Вовлечение + лид + персонализация оффера.

Бонус-приёмы: акции (−% в ДР, коллективная приёмка ЖК — приемка.москва); стена сертификатов/СРО (Ситипроф 12 шт.); отчёты по конкретным застройщикам с числом дефектов (profpriemka, Ситипроф); 4 способа заказа отдельным блоком (приемка.москва).

### Чего избегать (антипаттерны рынка)
- **Перегруз формами** (Догма 8+, asp-expert): размывает фокус, утомляет. Достаточно hero-CTA + калькулятор/квиз + 1 финальная форма + плавающая кнопка.
- **Обезличенность** (cityprof частично, profpriemka): «компания», нет живых лиц → именно тут отстраиваемся.
- **Стена юридического текста** (asp-expert): услуга тонет, нет визуала. Юр-аргументы давать дозированно, человеческим языком.
- **Тонкий/слабый региональный сайт без иерархии** (kenigmaster по приёмке — вообще 404; региональные часто без визуального ритма).
- **Агрессивный оффер «бесплатно через суд»** (Догма, asp-expert) — рискован при мораториях на неустойки (см. CLAUDE.md: сверять с 214-ФЗ). Не строить главный оффер на взыскании неустойки.
- **Дистанционка спрятана в FAQ** (profpriemka) — если это наша фишка, выносить в отдельную секцию hero-уровня.

### Рекомендации по порядку секций нашей главной
Наш план: Hero → трасты → лента этапов → что проверяем → услуги → дистанционная → гарантии/акт → эксперты → видео/кейсы → отзывы → гео → квиз → FAQ → footer.
**Подтвердилось практикой конкурентов** — порядок логичный и сильный. Корректировки:
1. **Hero** — оффер + 1 главный CTA + телефон/мессенджеры. ✅
2. **Трасты (цифры доверия)** сразу под hero — ✅ (так у всех топов).
3. **«Что проверяем» поднять ВЫШЕ ленты этапов** или сразу за трастами (иконки) — у profpriemka/Догма это рано и работает. Можно: Hero → трасты → что проверяем → лента этапов.
4. **Лента этапов (GSAP)** — наш процесс 4–5 шагов с акцентом на «бесплатную повторную». ✅
5. **Услуги** карточками с ценами-вилками (как priemka39) + калькулятор/квиз рядом. Калькулятор лучше поднять выше (не прятать к концу).
6. **Дистанционная приёмка** — отдельная секция с аргументом «экономия 2 приездов» (взято у profpriemka39) + мини-схема процесса + видео-кейс. ✅ Усилить, не прятать.
7. **Гарантии/акт** — официальный акт с печатью + фото с привязкой к квартире + бесплатная повторная. ✅ Сделать визуальный блок (показать сам акт).
8. **Эксперты (лица команды)** — ✅ ключевая отстройка, карточки с опытом/квалификацией НОПРИЗ/НОСТРОЙ.
9. **Видео/кейсы** — ✅ зона, где почти нет конкуренции в КЛН. Реальные приёмки на видео.
10. **Отзывы** — скрины + ссылки на Яндекс/2ГИС (как у всех). ✅
11. **Гео** — Зеленоградск/Светлогорск/Пионерский отдельными блоками/страницами (ниша свободна для приёмки). ✅
12. **Квиз** — ✅, лучше совместить с подбором оффера (иногородний → дистанционка).
